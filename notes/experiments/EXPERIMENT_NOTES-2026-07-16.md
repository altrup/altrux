## ROOT CAUSE FOUND + FIXED (23:41 UTC): unnormalized gated-delta write key

- detect-anomaly localized the recurring non-finite crash to write()'s internal loss (PowBackward0 NaN at model.py `(pred - vs) ** 2`); the whole memory path is fp32, so a genuine explosion, not precision.
- New instrumentation showed: failing slots had **ssm_norm = inf** while M's weights were tiny and finite, and k/v/knobs (projections of the residual) were already NaN — explosion arrives via the backbone state, not the memory MLP.
- Mechanism: `signals()` returned `key = key_proj(z)` **unnormalized**, but the delta merge's forget term only cancels exactly for a unit key. Per-write gain along the key is `retain·(1 − β·|key|²)` → below −1 once `|key|² > 2/β`. Stable while β ≈ 0.05 (anneal), goes unstable as β trains past ~0.3 — matches every signature: min_cos_sim pinned at −1, exponential ssm_norm growth (10 → 20 in 600 tokens, → inf deep into long examples), failures only in slots many-thousand tokens in.
- Verified with a standalone merge simulation: |key| ≈ 4.6 blows up in ~60 writes; normalized key stable indefinitely.
- Fix: `key = F.normalize(key_proj(z), dim=-1)` (commit 40acb98) — gain becomes `retain·(1 − β)`, stable for any learned β/retain in (0,1). Tests pass (45). Resumed 23:41, log train-20260716-234125.log; watching ssm_norm stays bounded as beta continues to climb.
